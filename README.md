# Kavita Jha — Twelve Rooms

The art of Kavita Jha as a dark, single-page exhibition in twelve rooms.

Live site: https://yatharth-jha-yx.github.io/Art-Showcase-Website-for-Kavita-Jha/

- `index.html` — the page (the "Twelve Rooms" design)
- `support.js`, `image-slot.js` — the scripts the page runs on
- `images/` — the artwork photos
- `Kavita Jha - Art Showcase.dc.html` — the earlier light version of the design

To update the site, edit the files, then commit and push to `main`. GitHub Pages republishes within a minute or two.
